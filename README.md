# SistemaSolar

Este proyecto es una simulación interactiva del Sistema Solar creada con Three.js.  
Permite visualizar el Sol, los planetas y sus lunas girando en torno al Sol, incluyendo anillos para Saturno y etiquetas dinámicas para identificar cada cuerpo celeste.

# Vista previa

Una representación tridimensional de los planetas girando en sus órbitas, con animación fluida y etiquetas flotantes que siguen a cada planeta.

# Tecnologías utilizadas

- HTML - Estructura base
- CSS - Estilos
- JavaScript - Lógica simulacion
- Three.js r128 (https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.js)
